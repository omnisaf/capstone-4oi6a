# 4OI6A Capstone — Group 2

The shared decision record for our capstone. Fall 2026 → April 2027.

## What this repo is for

**The Issues tab is the point.** Every open issue is a question we have not
answered yet. Every closed issue has the answer, and the reasoning, in its
comments.

Start at the issue labelled **`wayfinder:map`**. That one is the summary: where
we are going, what we have decided so far, and what is still unclear. Everything
else hangs off it.

You do not need to install anything to use this. Read the issues.

## Why it is set up this way

Writing a proposal is mostly answering questions in the right order. Most groups
answer them in a chat thread, and by week six nobody remembers why a decision
was made — only that it was.

Here, each decision is one issue. The question is the title. The answer is in
the comments. When the proposal gets written, the reasoning already exists.

## Module rule

Each member owns one **technical** module. These names are banned by the course:
*hardware, software, GUI, front-end, back-end, testing, integration.* A module
has to name what it actually does.
